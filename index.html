Descargas

Empieza ahora mismo.

Descarga el emisor para tu dispositivo y, si lo necesitas, el receptor para tu televisor.

Nota sobre los formatos: AirSend Android y AirReceive Android se distribuyen como archivos APK para Android. AirReceive para televisores LG es una aplicación webOS en formato IPK, no un APK de Android: no se puede instalar en un teléfono, y un APK no se puede instalar en un televisor LG. AirSend Chrome es una extensión en formato ZIP que se carga en el navegador. La compatibilidad depende del dispositivo, del sistema operativo, de su versión y de la aplicación instalada.

Instalación

Listo en unos minutos.

  1. Descarga el archivo APK de AirSend desde la sección de descargas.
  2. Instálalo en tu dispositivo Android. Si el sistema lo pide, autoriza la instalación desde esta fuente.
  3. Abre AirSend.
  4. Busca contenido con el buscador integrado, o selecciona el video, enlace o página que quieras enviar.
  5. Selecciona el dispositivo receptor y empieza a ver.
  1. Instala la extensión AirSend en Google Chrome.
  2. Abre Google Chrome.
  3. Accede a la extensión desde la barra de herramientas del navegador.
  4. Selecciona el contenido: un video, un enlace, una página web o la pestaña actual.
  5. Selecciona el dispositivo receptor y envía.

Si descargas el ZIP: descomprímelo, entra en chrome://extensions, activa el Modo de desarrollador y usa Cargar descomprimida seleccionando la carpeta. Cuando la extensión esté publicada en Chrome Web Store, el botón de descarga llevará directamente a la tienda.

  1. Instala la aplicación AirReceive compatible en tu televisor LG.
  2. Abre AirReceive en el televisor.
  3. Espera la conexión de AirSend desde tu teléfono Android o desde Google Chrome.

Formato webOS: AirReceive para LG es un paquete IPK para webOS. Su instalación depende del modelo de televisor y de las opciones que ofrezca el fabricante. Si la aplicación está publicada en la LG Content Store, instálala desde ahí.

  1. Descarga el archivo APK de AirReceive e instálalo en el dispositivo Android que vas a usar como receptor.
  2. Abre AirReceive.
  3. Deja el dispositivo preparado para recibir contenido desde AirSend.

Preguntas frecuentes

Las dudas más comunes.

¿Qué es AirSend?
AirSend es la aplicación emisora. Existe como aplicación para Android y como extensión para Google Chrome, y sirve para enviar videos, enlaces y páginas web a un dispositivo compatible conectado a tu televisor.
¿Qué es AirReceive?
AirReceive es la aplicación receptora. Se instala en un televisor LG compatible o en un dispositivo Android, y se encarga de recibir y mostrar el contenido que le envías desde AirSend.
¿Cuál es la diferencia entre emisor y receptor?
El emisor (AirSend) es desde donde eliges y envías el contenido: tu teléfono Android o tu navegador Chrome. El receptor (AirReceive) es donde se ve: el televisor o el dispositivo Android. Necesitas uno de cada para que la pareja funcione.
¿Puedo enviar desde Android?
Sí. Instala la aplicación AirSend para Android y envía desde tu teléfono o tableta.
¿Puedo enviar desde Google Chrome?
Sí. Instala la extensión AirSend en Google Chrome y envía desde tu ordenador.
¿Puedo enviar películas online?
La aplicación AirSend para Android incluye un buscador de películas online que te permite descubrir contenido disponible en la web y enviar el contenido compatible al televisor. AirSend no aloja ni distribuye contenido: los resultados provienen de sitios de terceros. Esta función no está disponible en la extensión de Chrome.
¿Puedo enviar una pestaña del navegador?
Sí, con la extensión AirSend para Google Chrome puedes enviar una pestaña del navegador.
¿Funciona con Chromecast?
Sí, Chromecast es uno de los destinos compatibles. La compatibilidad concreta depende del modelo del dispositivo y del contenido.
¿Funciona con Android TV?
Sí, AirSend puede enviar a televisores y reproductores con Android TV o Google TV compatibles.
¿Funciona con televisores LG?
Sí, en televisores LG compatibles. En este caso necesitas instalar AirReceive en el televisor para que pueda recibir el contenido.
¿Necesito instalar AirReceive?
Para enviar a un televisor LG o a un dispositivo Android como receptor, sí: AirReceive es la aplicación que recibe el contenido. Para enviar a Chromecast, Android TV o Google TV, no necesitas AirReceive.
¿Cómo instalo el APK?
Descarga el archivo APK desde la sección de descargas y ábrelo en tu dispositivo Android. Si el sistema te lo pide, autoriza la instalación de aplicaciones desde esta fuente. Los pasos exactos varían según la versión de Android.
¿Cómo instalo la extensión de Chrome?
Si la extensión está publicada en Chrome Web Store, instálala desde ahí con un clic. Si descargas el archivo ZIP, descomprímelo, abre chrome://extensions, activa el Modo de desarrollador y pulsa «Cargar descomprimida» seleccionando la carpeta.
¿Por qué la aplicación para LG no es un APK?
Los televisores LG usan el sistema webOS, que no ejecuta aplicaciones Android. Por eso AirReceive para LG se distribuye como un paquete IPK de webOS. Un APK no se puede instalar en un televisor LG, y un IPK no se puede instalar en un teléfono Android.
